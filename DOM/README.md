# 🖱️ Eventos DOM

Exercício prático de manipulação de eventos do DOM com JavaScript.

## 📋 O que o exercício faz

Uma caixa interativa que responde a três eventos de mouse:
- **Click** -> muda o texto e a cor para azul
- **Mouse Enter** -> muda o texto ao passar o cursor por cima
- **Mouse Out** -> muda o texto e a cor para marrom ao sair

## 🧠 Conceitos praticados

- Seleção de elementos com `getElementById`
- Registro de eventos com `addEventListener`
- Manipulação de texto com `innerText`
- Estilização dinâmica com `element.style`
